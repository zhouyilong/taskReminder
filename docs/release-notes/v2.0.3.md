## 改进
- 多设备同步更可靠：遇到更新版本才有的数据字段时，本机原样保留并在下次同步时带回，不会再因为某台设备没升级而把这些字段清空。
- 便签的“锚定”状态是本机设置，现在其他设备修改同一条待办后同步过来，本机的锚定状态也不会被取消。
- 网络组件升级，与自动更新共用同一套安全连接（TLS）实现，按系统证书库校验证书。
- 内置数据库引擎（SQLite）升级。

## 升级提示
- 本版本为将来的 2.1 做准备：2.1 会新增提前提醒、便签颜色等需要同步的字段。届时建议所有设备**至少升级到 2.0.3**：2.0.3 及以上的设备会保留并转交这些字段；2.0.2 及更早的设备上传后，云端会暂时缺少这些字段，这时新安装或重装的设备同步可能拿不到它们。
- 本版本没有新增设置，也不改变同步数据的格式，可以与 2.0.0 – 2.0.2 的设备混用同步。
