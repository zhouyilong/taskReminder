## 升级前请看
- 本版本新增了需要在设备之间同步的字段（循环提醒的结束日期与剩余次数、待办的项目）。**请把其他设备至少升级到 2.0.3**：2.0.3 及以上的设备会保留并转交这些字段；2.0.2 及更早的设备上传后，云端会暂时缺少这些字段，这时新安装或重装的设备同步可能拿不到它们。
- 还没有升级的设备不认识“结束条件”：循环提醒到达结束条件时会同时暂停，所以旧设备上它显示为“已暂停”、也不会再提醒；在旧设备上点“恢复”后，升级过的设备会在下一次提醒前把它改回暂停，不会多响。旧设备触发提醒时不会扣减剩余次数，多设备同时使用“共 N 次”时请尽量都升级。

## 新功能
- 循环提醒的结束条件：新建或编辑时可以设置“到某天为止”和“共几次”（都可留空，同时设置时先到的生效）。列表中显示“到 12月31日”“剩 3 次”，到期后状态变为“已结束”；修改结束条件（如把次数改为大于 0）后自动恢复。“跳过本次”不扣次数。也可以直接输入“每天8点 吃药 共7次”“每周一 9点 例会 到12月31日”“工作日 9点 站会 到年底”。
- 待办项目：在编辑弹窗中给待办设置项目，待办列表可按项目（或“未分组”）筛选，点击标题旁的项目徽标也能筛选；多选后可以“移到项目”。新建时输入“@项目名”即可，如“买瓷砖 @装修 #采购”。
- 搜索支持 @项目：全局搜索（Ctrl+K）与待办、已办的搜索框中输入“@装”即可只看“装修”项目的待办。

## 改进
- 导出：Markdown 中的待办按项目分组，循环提醒附上结束条件并标出“已结束”；日历（ICS）中的循环提醒带上结束日期或次数（`UNTIL` / `COUNT`），待办的项目作为分类导出。
- 创建、编辑或恢复循环提醒失败时（如结束日期早于第一次提醒）会提示原因，之前没有任何反应。

## 修复
- 在新建待办的描述或编辑弹窗中输入后立刻点“添加任务”/“确认”，最后输入的几个字可能丢失。
