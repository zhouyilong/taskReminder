# v3.0.0 发布说明

> **重要升级提示（致 2.2.x WebDAV 用户）**：  
> v3.0.0 **正式移除旧版 WebDAV 文件同步功能**，改由全新的自建云端服务提供实时同步。  
> - **升级前**：请先在旧版本中确保 WebDAV 同步已完成，使本机持有最新数据。  
> - **升级后**：您的全部本地待办、循环提醒、提醒记录与便签均会**无损保留**，应用默认以「本地模式」启动，旧版 WebDAV 密码与同步密码会在升级时自动清理；随后您可在「设置 → 运行模式」中一键登录并切换至「云端模式」，选择将本地数据合并到云端。

## 核心更新

### 1. 本地模式 / 云端模式自由切换与双向合并
- **双模式架构**：在「设置 → 运行模式」中随时切换 **本地模式**（纯本机 SQLite 离线使用）与 **云端模式**（按账号隔离的本地镜像库 + 实时推拉同步）。
- **标题栏状态徽标**：直观展示 `本地`、`云端 · 用户名` 或 `云端 · 已离线`（离线时点击徽标可一键触发切换至本地模式）。
- **安全双向合并**：
  - 本地 → 云端：自动先做本地快照备份，可选「合并本地数据到云端」或「直接切换（不合并）」；合并后原本地库保持不动，并内置**防跨账号串号警告**。
  - 云端 → 本地：即便完全断网，依然可将本机账号镜像库中的最新数据合并到本地库继续工作，联网后再切回云端无缝合并。

### 2. 全新 Rust + MySQL 单体云端服务（Docker 一键部署）
- 基于 Rust（Axum + Tokio + SQLx + MySQL 8.0）构建，与桌面端共享 `crates/core` 核心业务模型与 LWW 冲突裁决规则。
- **实时多端同步**：支持 350ms 写穿防抖增量 Push、游标 Pull 与 SSE 长连接实时通知，多设备修改秒级送达；墓碑软删除同步防复活。
- **极简部署与私有化自建**：提供多阶段 `server/Dockerfile`、`deploy/docker-compose.yml` 与低配 MySQL `my.cnf` 模板；客户端支持自定义服务端 URL 与连通性测试（公网明文 HTTP 自动警示）。

### 3. 极简两级角色与最小维护账号管理
- 不开放自助注册，服务端首次启动自动初始化管理员账号。
- 管理员在桌面端「设置 → 账号管理」即可直接完成账号列表查看（严格隐私隔离，不暴露其他用户业务内容）、创建账号（支持随机强密码生成与首次登录强制改密）、启用/禁用（即时吊销会话）、重置密码与级联删除账号。
- 服务端内置应急运维 CLI（`task-reminder-server admin list / create / reset-password / set-status`），可通过 `docker exec` 随时救急。
