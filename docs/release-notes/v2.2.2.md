## 升级前请看
- 本版本只修复便签拖动的问题，没有新增需要在设备之间同步的字段，也没有新增设置，与 2.0.3 及以上的设备混用没有新的注意事项。
- 便签不再响应 Windows 的窗口贴靠：拖到屏幕边缘时由应用自己的贴边吸附处理，不会再变成全屏或半屏。
- 拖出屏幕的便签松开后会收回到屏幕边缘。想故意把便签放到屏幕外一部分，松开鼠标时按住 Alt 即可。

## 修复
- 拖动便签时鼠标碰到屏幕顶边，便签会变成全屏；碰到左右边，便签会占半个屏幕；双击便签标题栏也会变成全屏。现在都不会了，拖动、调整大小的手感不变。
- 便签拖到屏幕边缘附近时感觉不到吸附，便签直接跑到屏幕外。现在：
  - 便签越过屏幕边缘或压到任务栏上，松开后贴回边缘；多屏时越过的部分在另一块屏幕上则保持原样。
  - 吸附距离从 12 像素加大到 16 像素，靠近屏幕边缘或其他便签时更容易贴上。
- 在缩放比例不同的两块屏幕之间拖动便签后不吸附的问题。

## 已知问题
- 之前被系统贴成全屏或半屏的便签，保存下来的尺寸不会自动恢复（开启同步时其他设备上也是这个尺寸），请手动把便签缩小一次。
