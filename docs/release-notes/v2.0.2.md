## 新功能
- 便签管理：侧边栏新增“便签”页，集中查看所有便签（显示中 / 已隐藏 / 已关闭），可按标题或内容搜索，一键置前、打开或关闭。
- 便签外观焕新：标题栏与页脚更紧凑，同样大小的便签能显示更多内容；操作按钮在鼠标悬停时出现，已勾选的待办项自动划掉。
- 便签贴边吸附（Windows）：拖动便签靠近屏幕边缘或其他便签时自动对齐，松开鼠标时按住 Alt 可跳过；可在设置中关闭。
- 在云同步设置中直接更换同步密码；其他设备会提示“同步密码不匹配”，填入新密码并保存即可恢复同步。
- 节假日数据在线更新：每天自动检查新一年的法定节假日安排，无需升级应用；也可在设置中点“立即检查”。

## 修复
- 便签位置落在屏幕外（例如来自另一台设备或已拔掉的显示器）时，打开时自动移回屏幕内，不会改动其他设备上的位置。
- 放在主屏左侧或上方副屏的便签，重启或重新打开后不再跑回主屏。
- 删除或完成待办时，它的便签窗口随之关闭（之前要重启应用才消失）。
- 打开便签不再产生多余的同步改动（之前会因编辑器重新排版，或位置、尺寸没变也写入而触发同步）。

## 升级提示
- 更换同步密码后，2.0.1 及更早版本的设备只会显示“同步失败”，请先升级到 2.0.2 再填写新密码。
- 便签贴边吸附、节假日自动更新都是本机设置，不会同步到其他设备。
- 本版本起，遇到更新版本才有的循环模式会原样保留并标为“需升级”，本机不提醒也不改写；2.0.1 及更早的版本仍会改写，将来新增循环模式时请多台设备一起升级。
- 节假日数据从 jsDelivr 或 GitHub 获取；网络不可用时不影响其他功能，也可以在数据目录放置 `holidays-cn.json` 手动补充。
