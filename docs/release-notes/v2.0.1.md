## 新功能
- 勿扰时段：期间到点的提醒照常记录但不弹窗，结束后一次弹出（设置 → 勿扰时段）。
- 系统通知：可选“同时发送系统通知”，全屏程序或游戏中也能看到提醒。
- 托盘显示下一条提醒，一次性待办可在托盘中直接完成或推迟 15 分钟。
- 托盘菜单一键显示/隐藏全部便签，也可在设置中录制全局快捷键。
- 日历周视图：按小时排列，拖动待办到某个时段即可改期。
- 云同步设置提供坚果云、Nextcloud、群晖预设。
- Windows 上的 WebDAV 密码与同步密码改存 Windows 凭据管理器，不再写入数据库与本地备份。
- 法定工作日提醒遇到还没有节假日数据的年份时给出提示。

## 修复
- 5 段 Cron 表达式的周字段按标准含义计算：`0 9 * * 1-5` 为周一至周五 9 点（之前会在周日到周四触发），`0` 与 `7` 都表示周日。

## 升级提示
- 之前按 `1-5` 等数字周几配置的 Cron 提醒，升级后触发日会改为标准含义；多台设备同步时请一起升级。
- 勿扰、系统通知、便签快捷键都是本机设置，不会同步到其他设备。
- Windows 上升级后密码会移入凭据管理器；如需退回 2.0.0，请在云同步设置中重新填写密码。
