## 升级前请看
- 本版本没有新增需要在设备之间同步的字段，与 2.0.3 及以上的设备混用没有新的注意事项。新增的“自动备份保留份数”是本机设置。
- 之前被 Windows 贴靠贴成全屏或半屏的便签，打开时会自动恢复为默认大小（并同步到其他设备），不用再手动缩小。
- 新增的“管理标签”可以批量重命名、合并、移除标签与项目。改动会写入每条相关的待办（含已完成）与循环提醒，开启云同步时会同步到其他设备。

## 新功能
- 管理标签与项目：待办页工具栏新增“管理标签”，列出所有标签（待办、已完成待办与循环提醒）与项目，以及各自用了多少条。
  - 重命名：改成已有的名称即合并，同一条上的重复标签会自动去掉。
  - 移除标签、把项目中的待办移出到“未分组”：只改标签或项目，不会删除条目。
  - 改名后，待办列表当前的标签、项目筛选会跟着换成新名称。
- 统计按项目汇总：统计页的“按标签”卡片新增“标签 / 项目”切换（有项目时显示），查看各项目的提醒次数、完成、推迟与处理率。循环提醒没有项目，计入“未分组”。
- 自动备份保留份数：“设置 → 自动备份保留”可选 7（默认）/ 14 / 30 份，调小后在下一次每日备份时删除更早的备份。“导入导出与备份”中新增“打开备份目录”。

## 修复
- 2.2.2 之前被 Windows 贴靠贴成全屏或半屏的便签，保存下来的尺寸不会自动恢复（2.2.2 的已知问题）。现在打开便签时，宽或高与所在屏幕几乎相同的会恢复为默认大小。

## 已知问题
- Windows 11 贴靠布局中的“四分之一屏”（半宽半高）无法与手动调大的便签区分，不会自动恢复，请手动缩小一次。
- 2027 年法定节假日安排尚未公布，公布后会通过在线更新提供（“设置 → 自动更新节假日数据”旁可“立即检查”），无需升级应用。
