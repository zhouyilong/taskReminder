## 升级前请看
- 默认安装目录改回英文的 `C:\Program Files\TaskReminderApp`（2.2.4 为 `C:\Program Files\任务提醒`）。从 2.2.4 默认目录升级的会自动移到新目录，之前自己选过其他目录的保持不变；数据、云同步设置与已保存的密码都不受影响，开机自启会在升级后第一次启动时改到新的安装位置。应用名称仍显示为“任务提醒”。
- 本版本新增了需要在设备之间同步的字段（待办的“加急”）。2.0.3 及以上的设备会保留并转交它，但**还没有升级的设备不显示加急标识**，在旧设备上编辑该待办也不会清掉加急。多设备同时使用时请尽量都升级。
- 待办清单便签的颜色只保存在本机，不会同步；清单的拖动排序与待办页的“手动顺序”共用，会同步到其他设备。

## 新功能
- 待办清单便签可以设置颜色：标题栏的色点中选择，可选颜色与普通便签相同。
- 待办清单可以拖动调整顺序：按住一条待办上下拖动，松开即保存。排过顺序的待办排在前面，之后新添加的排在后面；顺序与待办页“手动顺序”一致。
- 加急：鼠标移到清单中的待办上，点右侧的火焰图标设为加急（再点一次取消）。加急的待办整行标红，左侧有色条和醒目的“急”字，头部显示“N 项加急”；主窗口的待办列表中显示“加急”徽标，右键菜单也可以加急 / 取消加急。导出 Markdown 时标注“🔥 加急”。
- 便签一键复制：便签右上角新增“复制”按钮，复制正文（保留列表与勾选项，去掉编辑器的转义符号），正文为空时复制标题。

## 改进
- 待办清单改为**双击**打开待办的便签，单击、拖动、勾选都不会误打开。
- 待办清单左侧的圆圈改为方形勾选框：勾选后先打勾、文字划线，约 1 秒后再标记完成并淡出；这期间再点一次可以撤销。
- 在待办清单底部添加待办后，会自动在清单旁打开这条待办的便签，光标在正文中，可以直接补充内容（添加为循环提醒的除外）。

## 已知问题
- Windows 11 贴靠布局中的“四分之一屏”（半宽半高）无法与手动调大的便签区分，不会自动恢复，请手动缩小一次（同 2.2.3）。
- 2027 年法定节假日安排尚未公布，公布后会通过在线更新提供，无需升级应用。
