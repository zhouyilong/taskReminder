## 升级前请看
- 本版本没有新增需要同步的字段，可以和 2.2.6、2.2.7 的设备混用。

## 新功能
- 提醒记录可以快速批量勾选：表头的勾选框全选当前页；勾选一条后按住 Shift 再勾选另一条，中间的记录一并选中；选中后点“全选筛选结果”可以一次选中所有符合筛选条件的记录（不限于当前页），再点“删除所选”。已有选中的记录时，点击行也可以切换选择；按 Delete 删除、Esc 取消选择。
- 提醒记录新增“清理半年前”：一键删除半年前（当天零点之前）触发的全部提醒记录，确认框中会写明日期与条数。开启同步时，其他设备上的这些记录也会删除。
- 已办事项支持批量删除：点“多选”（或按住 Ctrl 点击行）后勾选，或全选本页、全选筛选结果，再点“删除”；删除后可在回收站中恢复。
- 所有列表的分页条可以直接跳到指定页：输入页码后回车或点“跳转”（超出范围时跳到第一页或最后一页），并新增“首页”“末页”按钮，每页条数增加“100 条/页”。
- 待办清单便签中右键点击待办，可以“复制标题”或“打开便签”；主窗口待办与已办列表的右键菜单也增加了“复制标题”。

## 已知问题
- Windows 11 贴靠布局中的“四分之一屏”（半宽半高）无法与手动调大的便签区分，不会自动恢复，请手动缩小一次（同 2.2.3）。
- 2027 年法定节假日安排尚未公布，公布后会通过在线更新提供，无需升级应用。
