## 升级前请看
- 本版本没有新增需要同步的字段，可以和 2.2.6 的设备混用。
- 便签与待办清单的默认颜色改为绿色：没有选过颜色的便签和清单会显示为绿色；颜色选择中不再有单独的“默认”。旧版本设备上这些便签仍显示原来的默认颜色。

## 改进
- 待办清单锚定时，从清单打开的便签（包括在清单中添加待办后打开的便签）也会自动锚定。
- 在便签中点“+”新建便签时，新便签放在当前便签旁边、不再叠在上面：右侧有空间就放右侧，否则依次放左侧、下方、上方；也会尽量避开其他已打开的便签。
- 从待办清单打开便签时，便签总是放在清单旁边（按右、左、下、上的顺序找有空间的一侧），不再沿用上次的位置；之后拖动便签仍会记住新位置。

## 已知问题
- Windows 11 贴靠布局中的“四分之一屏”（半宽半高）无法与手动调大的便签区分，不会自动恢复，请手动缩小一次（同 2.2.3）。
- 2027 年法定节假日安排尚未公布，公布后会通过在线更新提供，无需升级应用。
