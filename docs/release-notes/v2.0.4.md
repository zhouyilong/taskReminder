> 2.0.4 没有单独发布，以下改动随 2.1.0 一起发出（v2.1.0 的 Release 说明需补上这一节）。

## 新功能
- 待办批量操作：点“多选”或按住 Ctrl 点击行进入多选，Shift 连选、可全选本页，选中后可一次完成、删除、添加标签、设置优先级或修改提醒时间（支持“明天下午3点”这样的写法）。
- 循环提醒“跳过本次”：在循环提醒上点右键即可跳过下一次提醒，之后照常按规则提醒，不影响统计。
- 提醒弹窗中“稍后提醒”可以直接输入时间，如“明天下午3点”“30分钟后”“周五 9:00”，回车即可改期。
- 主窗口快捷键：Ctrl+N 新建、Ctrl+F 搜索、Alt+1…9 切换页面、Esc 关闭弹窗或退出多选、Delete 删除多选中的待办。设置中可查看说明。

## 修复
- “提示音”设置之前只保存、从不播放。现在新提醒弹出时会响一段短提示音（同时到达的多条只响一次，勿扰时段内不响），可在设置中试听或关闭。**升级后默认开启**，如不需要请在设置中关闭。
- 长时间（超过 60 天）没有同步的设备再次同步时，不会再把其他设备早已删除的待办和循环提醒重新带回来。

## 升级提示
- 本版本不改变同步数据的格式，可以与 2.0.0 – 2.0.3 的设备混用同步。
- 新增的同步记录（用于识别长期未同步期间的删除）只保存在本机，不会上传。
